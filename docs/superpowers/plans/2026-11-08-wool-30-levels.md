# 30 level, khối chéo 45°, 5 đường rồng, màn chọn level cuộn

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 30 level tất định, chơi được, độ khó tăng dần. Bảng trộn khối thẳng và khối xoay 45°. Đường rồng luân phiên 5 hình. Màn chọn level cuộn được và tự cuộn tới level hiện tại.

**Kiến trúc:**
- `WoolShape` (Runtime, thuần, có trong harness): footprint đa giác lồi, vùng quét, SAT ε = 1e-4, cắt theo bảng, khoảng cách ra khỏi bảng, `LaneClear`. Lưới cũ (`HasClearArrowLane` thủ công, `WoolRouting.IsClear`) bị thay bằng `WoolShape.LaneClear`.
- `WoolRouting`: độ dài đoạn tính Euclid (đoạn thẳng trục cho kết quả y hệt cũ), khối chéo chạy chéo tới vành đai rồi theo vành đai, `MaxHalf` chéo = nửa đường chéo footprint.
- `WoolPaths` (thuần): 5 bộ điểm điều khiển, lấy mẫu Catmull-Rom giống hệt `BuildLevels` cũ.
- `WoolSolver` (thuần): bộ giải tham lam dùng chung cho generator và `Validate All Levels`.
- `WoolLevelGenerator` (thuần): bảng độ khó 30 dòng, xếp khối theo thứ tự gỡ ngược, chia màu/len, chia đôi `Speed`.
- `Editor/WoolLevelAssets.cs`: menu `JamJam/Generate Levels` ghi `Level_1…30`, gán mảng level vào 2 scene.
- `WoolScene` vẽ khối chéo; `WoolLobby` tự cuộn.

**Tech Stack:** Unity 6000.3.19f1, URP 17.3, C# 9, uGUI, R3 1.3.1, .NET 10 harness, Python+PIL.

**Spec:** `docs/superpowers/specs/2026-11-08-wool-30-levels-design.md`

| PRNG (lệch nhỏ so với brief) | Không dùng `System.Random` (thuật toán seed của Mono và .NET không được hứa là trùng). Dùng SplitMix32 riêng (`WoolLevelGenerator.Rng`, chỉ phép `uint`). Seed `level·1000 + attempt` cho xếp khối, `seed·7 + 3` cho màu/capacity/len. Không dùng `Math.Sin/Cos` (CRT khác nhau): hằng `Diagonal = 0.70710678f`. Kiểm tất định bằng `Fingerprint` (FNV-1a 32 trên bit float và int): harness và Unity đều phải ra `096158D2`. |
| Lưới nửa ô | Khối thẳng: `X`,`Y` nguyên. Khối chéo: luôn `Width=2, Height=1`, tâm `(cx/2, cy/2)` với `cx ∈ [3, 2·Columns−3]`, `cy ∈ [3, 2·Rows−3]` (tâm cách mép ≥ 1.5 > nửa hộp 1.0607), nên `X = cx/2 − 1`, `Y = cy/2 − 0.5` là bội 0.5. Engine vẫn chấp nhận mọi W×H và mọi vị trí float (validate chỉ đòi footprint trong bảng ±1e-4, không chồng, hướng 0–7). |
| Góc xoay | θ = +45° (CCW, x phải y lên) cho `UpRight`/`DownLeft`, −45° cho `UpLeft`/`DownRight`. Đỉnh footprint theo thứ tự cục bộ `(−w,−h), (w,−h), (w,h), (−w,h)` (CCW). Khối thẳng tính đỉnh trực tiếp `(X,Y)…(X+W,Y+H)` để giữ số chính xác tuyệt đối như lưới. |
| Vùng quét | Bao lồi monotone chain (Andrew) của 8 điểm (footprint + footprint tịnh tiến), CCW, bắt đầu từ điểm x nhỏ nhất (y nhỏ nhất), bỏ điểm thẳng hàng (`cross ≤ 1e-7`). Khoảng cách quét = `ExitDistance` theo trục: nhỏ nhất của `(C − minX)/dx`, `maxX/−dx`, `(R − minY)/dy`, `maxY/−dy`. Phần hull dư ngoài bảng vô hại vì vật cản luôn nằm trong bảng (khối đang chạy được cắt theo bảng). |
| SAT | Trục = pháp tuyến các cạnh của cả hai đa giác; cạnh ngang/dọc dùng trục chính xác (0,1)/(1,0); chồng khi mọi trục có `min(max) − max(min) > 1e-4`. Lọc trước bằng AABB cùng ε (tương đương: độ xuyên nhỏ nhất của 2 đa giác lồi nằm trên một pháp tuyến cạnh). |
| Làn và khối đang chạy | `LaneClear(level, blocks, index, includeMoving)`: làn = vùng quét footprint của `index`. Vật cản: khối Phase 0 = footprint; khối Phase 1 (khi `includeMoving` và `Travel·Speed < ExitDistance`) = vùng quét từ vị trí hiện tại (công thức cũ `point.X/CellSize − (W − C)/2`, giữ góc θ lúc đứng) tới khi ra khỏi bảng, cắt theo bảng (Sutherland–Hodgman, điểm cắt gán đúng tọa độ mép). `WoolGame.HasClearArrowLane` = `LaneClear(…, true)`; `WoolRouting.TryFind` = `LaneClear(…, false)` (như `IsClear` cũ chỉ xét Phase 0). |
| Route chéo | Tia từ tâm theo `(±0.7071, ±0.7071)` tới hình chữ nhật vành đai (bảng giãn `RingOffset`). `alongZ ≤ alongX` ⇒ chạm cạnh trên/dưới (hòa thì coi là trên/dưới). Chạm trên: vào làn trên ngay. Chạm hông: đi lên theo hông. Chạm dưới: chọn trái/phải như hướng `Down` (`viaLeft <= viaRight`). `exitDistance` = độ dài Euclid đoạn đầu. Khối thẳng giữ nguyên nhánh code cũ. |
| Độ dài đoạn | `Distance(dx,dz)`: `dx==0 ⇒ |dz|`, `dz==0 ⇒ |dx|`, còn lại `sqrt`. Dùng trong `Length`, `Evaluate`, `Add`, `exitDistance`. Đoạn trục cho kết quả bit-identical với Manhattan cũ. |
| `MaxHalf` chéo | `sqrt(W²+H²)·CellSize/2` = 0.894 (2×1). `RingOffset` = 1.144, làn trên 8×6 ở z −2.856, mép khối −1.962 < −1.21 (`LaneFitsTray` đúng). |
| Hiển thị | Yaw nghỉ (Unity, độ, dương = cùng chiều kim đồng hồ nhìn từ trên) = `−θ`: `UpRight/DownLeft −45`, `UpLeft/DownRight +45`, thẳng 0. Mũi tên cục bộ quay `ArrowQuarter = round((Angle − RestYaw)/90) mod 4` (thẳng = d; chéo = 1 hoặc 3 ⇒ dọc cạnh dài). Heading khi chạy = `atan2(mx, mz)·deg − Angle(d) + RestYaw(d)`, `Angle` = góc la bàn `{0,90,180,270,45,135,225,315}`. |
| Collider | Giữ `BoxCollider` kích thước cục bộ cũ; xoay root bằng yaw nghỉ nên collider xoay theo. Check: AABB của collider khối chéo vuông (`extents.x ≈ extents.z ≈ (hw+hd)·0.7071`). |
| Check `Stage` | Thay hộp vuông nửa cạnh `MaxHalf` bằng 8 điểm trên đường tròn bán kính bao mesh `r = 0.5·CellSize·sqrt((W−2·Inset)²+(H−2·Inset)²)` = 0.7985 (bất biến theo góc xoay, là kích thước thật của khối đang quay đầu). Lý do: hộp vuông `MaxHalf` chéo cho `x = 4.344 + 0.894 = 5.238` > 5.184 dù mesh thật chỉ tới 5.143. Thêm vòng 5 hình `WoolPaths` (điểm ±0.66 và mèo ±1.1). |
| Xếp khối | Khối chéo đặt trước (bị gỡ sau cùng, nằm sâu), rồi khối thẳng. Mỗi bước: liệt kê **mọi** ứng viên (thẳng: 2 hướng dáng × mọi ô × 4 hướng; chéo: mọi tâm nửa ô × 4 hướng), lọc hợp lệ (trong bảng, `LaneFitsTray`, footprint không chồng và vùng quét không cắt footprint đã đặt), xáo bằng PRNG, chọn điểm tiếp xúc lớn nhất (hòa ⇒ phần tử đầu sau xáo). Tiếp xúc = tổng chiều dài chồng của các cặp cạnh song song (`|u×f| ≤ 1e-3`) cách nhau ≤ 0.1 (khối chéo song song lệch nửa ô cách nhau 0.0607). Hết ứng viên ⇒ seed hỏng. Khối lưu theo thứ tự đọc (tâm y giảm dần, rồi x tăng). |
| Màu, capacity, len | Bảng màu = hoán vị seed của 0..5, lấy `Colors` màu đầu; danh sách `i % Colors` xáo rồi gán theo thứ tự gỡ (mỗi màu ±1 khối).     static bool OldClear(LevelDefinition level, IReadOnlyList<BlockState> blocks, int index)
    {
        var a = blocks[index].Definition;
        const float epsilon = 0.0001f;
        for (var i = 0; i < blocks.Count; i++)
        {
            var other = blocks[i];
            if (i == index || other.Phase == 2) continue;
            var b = other.Definition;
            var x = b.X; var y = b.Y;
            var width = (float)b.Width; var height = (float)b.Height;
            if (other.Phase == 1)
            {
                WoolRouting.Evaluate(other.Route, other.Travel * WoolRouting.Speed, out var point, out _);
                x = point.X / WoolRouting.CellSize - (b.Width - level.Columns) * 0.5f;
                y = (point.Z - WoolRouting.BoardCenterZ) / WoolRouting.CellSize - (b.Height - level.Rows) * 0.5f;
            }
            var left = Math.Max(0, x); var right = Math.Min(level.Columns, x + width);
            var bottom = Math.Max(0, y); var top = Math.Min(level.Rows, y + height);
            if (other.Phase == 1 && right - left > epsilon && top - bottom > epsilon)
            {
                if (b.Direction == ExitDirection.Up) top = level.Rows;
                else if (b.Direction == ExitDirection.Down) bottom = 0;
                else if (b.Direction == ExitDirection.Right) right = level.Columns;
                else left = 0;
            }
            if (right - left <= epsilon || top - bottom <= epsilon) continue;
            var overlapX = a.X < right - epsilon && a.X + a.Width > left + epsilon;
            var overlapY = a.Y < top - epsilon && a.Y + a.Height > bottom + epsilon;
            if ((a.Direction == ExitDirection.Up && overlapX && top > a.Y + a.Height + epsilon) ||
                (a.Direction == ExitDirection.Down && overlapX && bottom < a.Y - epsilon) ||
                (a.Direction == ExitDirection.Right && overlapY && right > a.X + a.Width + epsilon) ||
                (a.Direction == ExitDirection.Left && overlapY && left < a.X - epsilon)) return false;
        }
        var steps = a.Direction == ExitDirection.Up ? level.Rows - a.Y : a.Direction == ExitDirection.Down ? a.Y + a.Height :
            a.Direction == ExitDirection.Right ? level.Columns - a.X : a.X + a.Width;
        var sx = a.Direction == ExitDirection.Right ? 1 : a.Direction == ExitDirection.Left ? -1 : 0;
        var sy = a.Direction == ExitDirection.Up ? 1 : a.Direction == ExitDirection.Down ? -1 : 0;
        for (var step = 1; step <= steps; step++)
            for (var i = 0; i < blocks.Count; i++)
            {
                if (i == index || blocks[i].Phase != 0) continue;
                var o = blocks[i].Definition;
                var px = a.X + sx * step; var py = a.Y + sy * step;
                if (px < o.X + o.Width && px + a.Width > o.X && py < o.Y + o.Height && py + a.Height > o.Y) return false;
            }
        return true;
    }

    static void RandomBoard(Random random, out LevelDefinition level)

        var blocks = new List<BlockDefinition>();

        var attempts = random.Next(4, 40);
        for (var n = 0; n < attempts; n++)
        {

            if (size[0] > columns || size[1] > rows) continue;

            var y = random.Next(rows - size[1] + 1);
            var free = true;
            for (var i = x; i < x + size[0]; i++) for (var j = y; j < y + size[1]; j++) free &= !occupied[i, j];
            if (!free) continue;
            for (var i = x; i < x + size[0]; i++) for (var j = y; j < y + size[1]; j++) occupied[i, j] = true;
            blocks.Add(new BlockDefinition { X = x, Y = y, Width = size[0], Height = size[1], Direction = (ExitDirection)random.Next(4), Color = 0, Capacity = 1 });
        }
        if (blocks.Count == 0) blocks.Add(new BlockDefinition { X = 0, Y = 0, Width = 1, Height = 1, Color = 0, Capacity = 1 });
        level = new LevelDefinition { Columns = columns, Rows = rows, Slots = 6, PathLength = 1000, InitialHead = 1, Speed = 0.001f, Spacing = 0.1f, Blocks = blocks.ToArray(), Yarn = new int[blocks.Count] };
    }

    static void Compare(WoolGame game, LevelDefinition level)
    {
        var free = false;
        for (var s = 0; s < game.OpenSlots; s++) free |= game.Spools[s].Block < 0;
        for (var i = 0; i < game.Blocks.Count; i++)
        {
            var expected = free && game.Status == RoundStatus.Playing && game.Blocks[i].Phase == 0 && OldClear(level, game.Blocks, i);
            if (game.CanSelect(i) != expected) throw new InvalidOperationException("Grid oracle mismatch on board " + Boards + " block " + i);
            Comparisons++;
        }
    }

    static void Frame(LevelDefinition data)
    {

        var tablet = WoolStage.Size(0.75f);

        foreach (var block in data.Blocks)
        {
            var width = block.Width - 2 * 0.09f;
            var height = block.Height - 2 * 0.09f;
            var radius = 0.5f * WoolRouting.CellSize * (float)Math.Sqrt(width * width + height * height);
            for (var slot = 0; slot < 6; slot++)
            {
                Check(WoolRouting.TryFind(data, new[] { new BlockState { Definition = block } }, 0, slot, out var route, out _), "Generated block reaches slot " + slot);
                foreach (var p in route)
                {
                    var low = (p.Z - radius - WoolStage.TargetZ) * sin;
                    var high = (p.Z + radius - WoolStage.TargetZ) * sin;
                    Check(Math.Abs(p.X) + radius < halfX && low > -tablet + WoolStage.BottomBand && high < tablet - WoolStage.HudBand, "Ring route stays inside the frame");
                }
            }
        }
    }

using System;

namespace JamJam
{
    public static class WoolSolver
    {
        public const float Delta = 0.02f;
        public const int MaxFrames = 30000;
        public const float TapInterval = 1f;

        public static void Run(LevelDefinition data, out bool won, out float peak, out float elapsed)
        {
            var game = new WoolGame(data);
            peak = game.Head / game.PathLength;
            var wait = 0f;
            for (var frame = 0; frame < MaxFrames && game.Status == RoundStatus.Playing; frame++)
            {
                wait -= Delta;
                if (wait <= 0)
                    for (var b = 0; b < game.Blocks.Count; b++)
                        if (game.Blocks[b].Phase == 0 && game.HasVisibleColor(game.Blocks[b].Definition.Color) && game.CanSelect(b))
                        {
                            game.Select(b);
                            wait = TapInterval;
                            break;
                        }
                game.Step(Delta);
                peak = Math.Max(peak, game.Head / game.PathLength);
            }
            won = game.Status == RoundStatus.Won;
            elapsed = game.Elapsed;
        }
    }
}

        public static bool TryLayout(WoolLevelRecipe recipe, int seed, out IReadOnlyList<BlockDefinition> blocks, out IReadOnlyList<int> removal)
        {
            var rng = new Rng(seed);
            var kinds = new List<bool>();
            for (var i = 0; i < recipe.Blocks; i++) kinds.Add(i < recipe.Diagonals);
            var placed = new List<BlockDefinition>();

            var level = new LevelDefinition { Columns = recipe.Columns, Rows = recipe.Rows };
            foreach (var diagonal in kinds)
            {
                var candidates = new List<BlockDefinition>();
                Candidates(recipe.Columns, recipe.Rows, diagonal, candidates);
                var valid = new List<BlockDefinition>();
                foreach (var candidate in candidates)
                    if (Fits(level, candidate, footprints)) valid.Add(candidate);
                if (valid.Count == 0) { blocks = Array.Empty<BlockDefinition>(); removal = Array.Empty<int>(); return false; }
                rng.Shuffle(valid);
                var best = valid[0];
                var bestScore = -1f;

                    var score = Contact(footprint, footprints);
                    if (score > bestScore + 1e-4f) { bestScore = score; best = valid[i]; }
                }
                WoolShape.Footprint(best, out var chosen);
                placed.Add(best);
                footprints.Add(chosen);
            }
            var order = new List<int>();
            for (var i = 0; i < placed.Count; i++) order.Add(i);
            order.Sort((a, b) =>
            {

                var by = placed[b].Y + placed[b].Height * 0.5f;
                if (ay != by) return by.CompareTo(ay);
                var ax = placed[a].X + placed[a].Width * 0.5f;
                var bx = placed[b].X + placed[b].Width * 0.5f;
                return ax != bx ? ax.CompareTo(bx) : a.CompareTo(b);

            for (var i = 0; i < order.Count; i++) { sorted[i] = placed[order[i]]; index[order[i]] = i; }
            blocks = sorted;
            var sequence = new int[placed.Count];
            for (var i = 0; i < placed.Count; i++) sequence[i] = index[placed.Count - 1 - i];
            removal = sequence;
            return true;

        static void Candidates(int columns, int rows, bool diagonal, List<BlockDefinition> list)
        {

        static bool Fits(LevelDefinition level, BlockDefinition candidate, List<IReadOnlyList<ShapePoint>> footprints)
        {
            WoolShape.Footprint(candidate, out var footprint);
            if (!WoolShape.Inside(footprint, level.Columns, level.Rows)) return false;
            if (!WoolRouting.LaneFitsTray(level, candidate)) return false;
            WoolShape.Lane(footprint, candidate.Direction, level.Columns, level.Rows, out var lane);
            foreach (var other in footprints)
                if (WoolShape.Overlaps(footprint, other) || WoolShape.Overlaps(lane, other)) return false;
            return true;
        }

        static float Contact(IReadOnlyList<ShapePoint> footprint, List<IReadOnlyList<ShapePoint>> footprints)
        {
            var total = 0f;
            foreach (var other in footprints) total += Touch(footprint, other);
            return total;
        }

        static float Touch(IReadOnlyList<ShapePoint> a, IReadOnlyList<ShapePoint> b)
        {
            var total = 0f;
            for (var i = 0; i < a.Count; i++)
            {
                var a0 = a[i]; var a1 = a[(i + 1) % a.Count];
                var ex = a1.X - a0.X; var ey = a1.Y - a0.Y;
                var length = (float)Math.Sqrt(ex * ex + ey * ey);
                var ux = ex / length; var uy = ey / length;
                for (var j = 0; j < b.Count; j++)
                {
                    var b0 = b[j]; var b1 = b[(j + 1) % b.Count];
                    var fx = b1.X - b0.X; var fy = b1.Y - b0.Y;
                    if (Math.Abs(ux * fy - uy * fx) > 1e-3f * Math.Max(1f, Math.Abs(fx) + Math.Abs(fy))) continue;
                    if (Math.Abs((b0.X - a0.X) * uy - (b0.Y - a0.Y) * ux) > ContactGap) continue;
                    var s0 = (b0.X - a0.X) * ux + (b0.Y - a0.Y) * uy;
                    var s1 = (b1.X - a0.X) * ux + (b1.Y - a0.Y) * uy;
                    var overlap = Math.Min(length, Math.Max(s0, s1)) - Math.Max(0, Math.Min(s0, s1));
                    if (overlap > 0) total += overlap;
                }
            }
            return total;
        }

        static void Build(WoolLevelRecipe recipe, int seed, IReadOnlyList<BlockDefinition> layout, IReadOnlyList<int> removal, float length, out LevelDefinition data)
        {
            var blocks = new BlockDefinition[layout.Count];
            for (var i = 0; i < blocks.Length; i++) blocks[i] = layout[i];
            var rng = new Rng(seed * 7 + 3);
            var palette = new List<int> { 0, 1, 2, 3, 4, 5 };
            rng.Shuffle(palette);
            var colors = new List<int>();
            for (var i = 0; i < blocks.Length; i++) colors.Add(palette[i % recipe.Colors]);
            rng.Shuffle(colors);
            for (var i = 0; i < removal.Count; i++)
            {
                var block = blocks[removal[i]];
                block.Color = colors[i];
                block.Capacity = rng.Range(3, recipe.MaxCapacity + 1);
                blocks[removal[i]] = block;
            }
            var yarn = new List<int>();
            foreach (var index in removal)
                for (var c = 0; c < blocks[index].Capacity; c++) yarn.Add(blocks[index].Color);
            for (var i = 0; i < yarn.Count && recipe.Window > 0; i++)
            {
                var j = Math.Min(yarn.Count - 1, i + rng.Range(0, recipe.Window + 1));
                var swap = yarn[i]; yarn[i] = yarn[j]; yarn[j] = swap;
            }
            data = new LevelDefinition
            {
                Columns = recipe.Columns, Rows = recipe.Rows, Slots = 4, PathLength = length,
                InitialHead = (float)Math.Round(recipe.HeadShare * length, 2), Speed = MinSpeed / 1000f, Spacing = recipe.Spacing,
                Blocks = blocks, Yarn = yarn.ToArray()
            };
        }

        public static uint Fingerprint(LevelDefinition data)
        {

            Mix(data.Columns); Mix(data.Rows); Mix(data.Slots);
            Mix(BitConverter.SingleToInt32Bits(data.PathLength)); Mix(BitConverter.SingleToInt32Bits(data.InitialHead));
            Mix(BitConverter.SingleToInt32Bits(data.Speed)); Mix(BitConverter.SingleToInt32Bits(data.Spacing));

                Mix(block.Width); Mix(block.Height); Mix((int)block.Direction); Mix(block.Color); Mix(block.Capacity);
            }
            foreach (var color in data.Yarn) Mix(color);
            return hash;
        }

        public static bool TryTune(LevelDefinition data, float target, out float ratio)
        {
            data.Speed = MinSpeed / 1000f;
            WoolSolver.Run(data, out var won, out ratio, out _);
            if (!won || ratio > target + Tolerance) return false;
            var low = MinSpeed;
            var lowRatio = ratio;
            var high = MaxSpeed;
            var highRatio = 2f;
            while (high - low > 1)
            {
                var mid = (low + high) / 2;
                data.Speed = mid / 1000f;
                WoolSolver.Run(data, out won, out var value, out _);
                if (!won) value = 2f;
                if (value < target) { low = mid; lowRatio = value; }
                else { high = mid; highRatio = value; }
            }
            var pickHigh = highRatio <= 1f && Math.Abs(highRatio - target) < Math.Abs(lowRatio - target);
            data.Speed = (pickHigh ? high : low) / 1000f;
            ratio = pickHigh ? highRatio : lowRatio;
            return Math.Abs(ratio - target) <= Tolerance;
        }
